# Castor Documentation

Documentation site for [Castor](https://github.com/substratum-labs/castor): a secure microkernel for LLM agents.

Built with [Docusaurus](https://docusaurus.io/).

## Contents

- **Docs:** Getting started, architecture, guides
- **Whitepaper:** Academic-style treatment of Castor's design
- **Blog:** Technical deep-dives from the Castor team

## Development

```bash
npm install   # Install dependencies
npm start     # Start dev server (http://localhost:3000)
npm run build # Production build
npm run serve # Serve production build locally
```

## Deployment

Automatically deployed to GitHub Pages via `.github/workflows/deploy.yml` on push to `main`.
